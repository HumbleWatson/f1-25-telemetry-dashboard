# i18n 国际化 — 设计规格 (zh-CN)

日期：2026-06-30

## 概述

为 Pits n' Giggles 的两个前端添加简体中文（zh-CN）国际化支持。当前两个前端均为纯英文，没有任何国际化基础设施。

## 范围

- **主要：** `apps/frontend/`（Vanilla JS 仪表盘，约 220-270 个字符串）
- **次要：** `apps/external/f1-save-viewer/`（React 离线查看器，约 110-145 个字符串）
- **语言：** en（默认）+ zh-CN
- **排除项：** Python 后端字符串、CSS 内容、纯数据值（圈速、车手名等）

## 翻译数据

统一 JSON 文件位于 `apps/frontend/i18n/translations.json`，按语言再按命名空间分层：

```json
{
  "en": {
    "common": { "loading": "Loading...", "na": "N/A", "leader": "Leader" },
    "raceTable": { "pos": "POS", "driver": "DRIVER", "bestLap": "BEST LAP" }
  },
  "zh-CN": {
    "common": { "loading": "加载中...", "na": "无", "leader": "领跑者" },
    "raceTable": { "pos": "名次", "driver": "车手", "bestLap": "最快圈" }
  }
}
```

- 点号分隔键：`__("raceTable.pos")`
- 支持插值：`__("toast.speedChanged", { value: "km/h" })`
- 单份主文件。React 端在 `src/i18n/locales/` 维护按语言拆分的副本，从主文件同步

## 1. Vanilla JS 仪表盘（`apps/frontend/`）

### 架构

新增文件 `apps/frontend/js/i18n.js`：

```
i18n.js 职责：
  - 启动时 fetch translations.json
  - 暴露全局 window.__() 函数
  - 在 localStorage 中管理当前语言（键名："png_lang"）
  - 语言切换时触发 i18n:change 事件
  - 更新 document.documentElement.lang
```

### `__(key, params)` 实现

```js
function __(key, params) {
  const lang = getCurrentLang();
  const value = key.split('.').reduce((o, k) => o?.[k], translations[lang]);
  if (!value) return key;
  return params
    ? value.replace(/\{(\w+)\}/g, (_, k) => params[k] ?? `{${k}}`)
    : value;
}
```

### 语言选择

在已有的设置弹窗（driver-view.html）中添加 `<select>` 下拉框。选项：English / 简体中文。切换时保存到 localStorage、更新 `document.documentElement.lang`、触发事件。

### 迁移策略

逐个文件将 JS 中的硬编码英文字符串替换为 `__()` 调用：
1. `app.js` — toast 通知、状态文本、点击处理器标签
2. `utils.js` — `showToast()` 消息、格式化标签
3. `raceTableRowPopulator.js` — 表格表头、单元格标签
4. `modals.js`、`driverDataModalPopulator.js`、`raceStatsModalPopulator.js` — 弹窗内容
5. 其余文件增量替换

HTML Jinja2 模板保持英文（主要包含结构文本）；优先处理 JS 注入的动态文本。

### 无破坏性保障

- `__()` 在翻译缺失时回退显示键本身
- 英文始终作为源语言完整填充
- 语言切换纯客户端操作，无需刷新页面

## 2. React 离线查看器（`apps/external/f1-save-viewer/`）

### 架构

- 通过 pnpm 添加 `i18next` + `react-i18next` 依赖
- 在 `src/i18n/i18n.ts` 中初始化
- 按语言拆分的 JSON 文件位于 `src/i18n/locales/`（从主 `translations.json` 同步）
- 在布局的页头/侧边栏添加 `LanguageSwitcher` 组件

### 实现细节

```typescript
// src/i18n/i18n.ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';

import en from './translations/en.json';
import zhCN from './translations/zh-CN.json';

i18n.use(initReactI18next).init({
  resources: { en: { translation: en }, 'zh-CN': { translation: zhCN } },
  lng: localStorage.getItem('png_lang') || 'en',
  fallbackLng: 'en',
  interpolation: { escapeValue: false },
});
```

- 组件使用 `useTranslation()` hook
- 共享 UI 基础组件（Button、Badge 等）通过 props 接收翻译后的标签（不与 i18n 耦合）
- 数据分析驱动的字符串保持英文（由后端格式化）

## 实施顺序

1. 添加 `translations.json`，填充所有英文字符串（基线）
2. 在仪表盘中实现 `i18n.js` + 语言切换器
3. 逐个文件翻译并迁移 Vanilla JS 仪表盘字符串
4. 在 React 离线查看器中添加 i18next + 翻译
5. 验证：切换语言、刷新、检查所有 UI 界面

## 非目标

- 不涉及后端国际化（后端发送原始数据，显示格式在客户端处理）
- 不处理复数规则（当前规模不需要，可后续添加）
- 不支持 RTL
- 不使用自动翻译
- Vanilla JS 部分不引入模块打包器
